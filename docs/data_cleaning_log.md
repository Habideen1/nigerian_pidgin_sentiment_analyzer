# Data Cleaning Log

The following preprocessing operations were applied:

- Converted text to lowercase.
- Removed URLs.
- Removed mentions.
- Removed hashtags.
- Removed punctuation.
- Removed numbers.
- Removed extra whitespace.
- Tokenized text.
- Removed English and Nigerian Pidgin stopwords.
- Rejoined cleaned tokens into final_text.
- Removed duplicate rows.
- Exported cleaned dataset to dataset/processed/train_processed.csv.
